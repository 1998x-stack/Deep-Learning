# Content roadmap

## Delivered first batch

1. XOR and the expressive limit of a linear classifier.
2. Gradient descent, mini-batches, backpropagation and optimizer responsibilities.
3. Loss functions, likelihood and regularization.
4. Output units for regression, binary, multiclass and multilabel tasks.
5. Hidden units as learned representations.
6. ReLU and its piecewise-linear family.
7. Logistic sigmoid and tanh.
8. Softplus, ELU/SELU, Swish, GELU, Mish and Maxout.

## Suggested next batch

- Network architecture: depth, width, skip connections and parameter sharing.
- Universal approximation: what the theorem says and what it does not say.
- Computational graphs and the chain rule.
- Backpropagation through a fully connected MLP.
- Gradient checking and numerical differentiation.
- Initialization, normalization and gradient-flow diagnostics.

Every new batch should reuse the evidence ledger, SVG, MathML, executable example and browser QA gates.
